# Инструкции для Claude

Это репозиторий YouTube-канала. Язык контента и документов — русский.

## Перед работой
- Прочитай `channel/positioning.md`, `channel/audience.md` и `channel/style-guide.md` —
  весь контент должен соответствовать им.
- Новые ролики создавай копированием `videos/_template/` (шортсы — `shorts/_template/`).

## Правила
- Не коммить тяжёлые медиафайлы (видео, исходники, WAV) — они в `.gitignore`.
- Обновляй `calendar/content-plan.md`, когда меняется статус ролика.
- Статусы ролика: `идея` → `бриф` → `сценарий` → `раскадровка` → `производство` → `опубликовано` → `разобрано`.
- Публикацию видео, ответы на комментарии и любые публичные действия через vidIQ
  выполняй только после явного подтверждения владельца канала.
- Аналитические отчёты сохраняй в `analytics/reports/`.
