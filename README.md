# YouTube-канал: рабочий репозиторий

Здесь живёт всё, что нужно для канала: стратегия, идеи, сценарии, контент-план,
аналитика и исследования. Тяжёлые медиафайлы (исходники видео, рендеры) в Git
не хранятся — только тексты, планы и лёгкие ассеты.

## Структура

```
channel/        Стратегия канала: позиционирование, аудитория, стиль
ideas/          Бэклог идей для роликов и шортсов
calendar/       Контент-план и график публикаций
research/       Конкуренты, ключевые слова, тренды
videos/         Папка на каждый длинный ролик (бриф → сценарий → раскадровка → публикация)
shorts/         Папка на каждый шортс
analytics/      Метрики и отчёты по каналу и роликам
assets/         Брендинг, превью, музыка, звуки (лёгкие файлы)
scripts/        Скрипты автоматизации
```

## Жизненный цикл ролика

1. **Идея** — запись в `ideas/backlog.md`.
2. **Исследование** — ключевые слова и конкуренты в `research/`.
3. **Бриф** — копируем `videos/_template/` в `videos/ГГГГ-ММ-ДД-slug/`, заполняем `brief.md`.
4. **Сценарий** — `script.md`.
5. **Раскадровка** — `storyboard.md`.
6. **Производство** — съёмка/генерация, озвучка, монтаж (исходники вне Git).
7. **Публикация** — заголовок, описание, теги, превью в `publish.md`; дата в `calendar/content-plan.md`.
8. **Разбор** — через 7 и 28 дней метрики в `analytics/`.

## Именование

- Папки роликов: `videos/2026-11-05-kak-vybrat-mikrofon/` (дата публикации + slug латиницей).
- Шортсы: `shorts/2026-11-06-mikrofon-za-60-sekund/`.
- Отчёты: `analytics/reports/2026-11-weekly.md`.
